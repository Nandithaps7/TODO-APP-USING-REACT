# Todo App

This project is a simple Todo application built to manage daily tasks efficiently.  
It allows users to add, view, and organize tasks in a clean and minimal interface, focusing on usability and clarity.

The application is designed as a beginner-friendly project to understand how task-based applications are structured on the frontend.

---------------------------------------------------------------------

## Key Features

- Add new tasks
- View a list of pending tasks
- Simple and clean user interface
- Easy-to-understand layout
- Lightweight and fast
- Beginner-friendly code structure

---

## Technologies Used

- HTML
- CSS
- JavaScript
- Basic DOM manipulation

---

## Project Objective

This project was created to:
- Practice JavaScript fundamentals
- Understand DOM manipulation
- Learn how user input is handled in web applications
- Build a practical and useful mini-project
- Strengthen frontend development basics

---

## Usage

- Open the application in a web browser
- Add tasks using the input field
- Manage your daily tasks easily in one place

---

## Note

This is a simple Todo application created for **learning and practice purposes**.  
It does not include backend storage or database considerations.
